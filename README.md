## 2. Описание проекта

Данный проект предназначен для оценки качества обслуживания клиентов с помощью веб-приложения. Клиенты смогут выставлять оценки, оставлять отзывы и комментарии о полученных услугах. Руководство организации сможет просматривать результаты оценивания, анализировать отзывы и определять направления улучшения качества обслуживания.

## 3. Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр доступных услуг.
- Оценка качества обслуживания.
- Добавление отзывов и комментариев.
- Просмотр и анализ оценок клиентов.
- Формирование статистических отчётов.
