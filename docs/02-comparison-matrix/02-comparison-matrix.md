# Сравнительная матрица аналогов: веб-проект оценки качества обслуживания клиентами

**Цель:** сравнить существующие системы оценки качества обслуживания, определить их преимущества и недостатки, а также выбрать решения, которые будут использованы при разработке собственного веб-проекта.

**Дата проверки данных:** 10.11.2026.

## 1. Критерии сравнения

Для сравнения аналогов выбраны функциональные и нефункциональные критерии. Функциональные критерии показывают, какие возможности предоставляет система, а нефункциональные характеризуют удобство, доступность и технические особенности.
| № | Критерий | Как оцениваем | Вес |
|---|---|---|---|
| K1 | Регистрация и авторизация клиентов | 0 — отсутствует; 1 — только регистрация или авторизация; 2 — есть обе функции | 2 |
| K2 | Оценка качества обслуживания по критериям | 0 — отсутствует; 1 — общая оценка без критериев; 2 — оценка по нескольким критериям | 3 |
| K3 | Возможность оставлять текстовые отзывы | 0 — отсутствует; 1 — только короткий комментарий; 2 — полноценный текстовый отзыв | 2 |
| K4 | Анализ оценок и формирование отчётов | 0 — отсутствует; 1 — просмотр оценок; 2 — статистика, фильтрация и отчёты | 3 |
| K5 | Язык интерфейса | 0 — нет русского и таджикского; 1 — есть один из этих языков; 2 — доступны оба языка | 2 |
| K6 | Мобильная версия | 0 — не адаптирован для телефона; 1 — адаптивный сайт; 2 — есть также мобильное приложение | 2 |
| K7 | Стоимость использования | 0 — платная система без бесплатного тарифа; 1 — есть ограниченный бесплатный тариф; 2 — основные функции бесплатны | 1 |
| K8 | Скорость загрузки сайта (PageSpeed) | 0 — от 0 до 49; 1 — от 50 до 89; 2 — от 90 до 100 | 2 |

**Максимальный результат:** 34 балла (сумма всех весов × 2).

## 5. Итоговые результаты

Итоговый балл рассчитывается по формуле:

**Итоговая сумма = сумма (балл × вес критерия).**

Максимальный результат по всем критериям составляет 34 балла.

| Аналог | Взвешенная сумма | Максимум по проверенным критериям | Результат |
|---|---:|---:|---:|
| 2ГИС | 22 | 32 | 68,75 % |
| SurveyMonkey | 20 | 24 | 83,33 % |
| LimeSurvey | 20 | 22 | 90,91 % |

**Расчёт для 2ГИС:**

2 × 2 + 1 × 3 + 2 × 2 + 1 × 3 + 1 × 2 + 2 × 2 = 20.

Максимум: 2 × (2 + 3 + 2 + 3 + 2 + 2) = 28.

**Расчёт для SurveyMonkey:**

2 × 3 + 2 × 2 + 2 × 3 + 2 × 2 = 20.

Максимум: 2 × (3 + 2 + 3 + 2) = 20.

**Расчёт для LimeSurvey:**

2 × 3 + 2 × 2 + 2 × 3 + 1 × 2 + 2 × 1 = 20.

Максимум: 2 × (3 + 2 + 3 + 2 + 1) = 22.

**Примечание:** проценты рассчитаны только по проверенным критериям. Поэтому 100 % у SurveyMonkey не означает, что система лучше остальных по всем характеристикам. Для окончательного сравнения необходимо проверить недостающие данные и измерить скорость сайтов через PageSpeed Insights.
## 6. Выводы

По результатам сравнения аналогов определены решения, которые будут использоваться при разработке собственного веб-проекта оценки качества обслуживания клиентами.

### 6.1. Что заимствуем

1. **(K2)** Используем систему оценивания по нескольким критериям, чтобы клиенты могли отдельно оценивать вежливость, скорость и качество обслуживания.
2. **(K3)** Добавим возможность оставлять текстовые отзывы, чтобы клиенты могли подробно описывать свои впечатления.
3. **(K4)** Реализуем статистику, фильтрацию оценок и формирование отчётов для руководителя.

### 6.2. Что не будем делать

1. Не будем создавать сложную публичную платформу отзывов с рейтингами организаций, как в 2ГИС. Наш проект будет предназначен для внутренней оценки качества обслуживания конкретной организации.

### 6.3. В чём наше отличие

1. **(K5)** Предусмотрим интерфейс на русском и таджикском языках, чтобы системой могли пользоваться разные категории клиентов.
2. **(K4, K6)** Создадим простую адаптивную веб-систему, в которой клиенты смогут оставлять оценки с телефона, а руководство — анализировать результаты.

### Общий вывод

Сравнение показало, что существующие системы предоставляют полезные инструменты для сбора отзывов и анализа ответов. Однако наш проект будет ориентирован на конкретную организацию, её сотрудников и качество обслуживания. Это позволит упростить процесс получения обратной связи и повысить эффективность анализа удовлетворённости клиентов.
