# Анализ предметной области: веб-проект оценки качества обслуживания клиентами

## 1. Организация

Предметной областью данного проекта является деятельность организации, предоставляющей услуги клиентам. Для повышения качества обслуживания организация использует веб-проект, с помощью которого клиенты могут оценивать полученные услуги и оставлять отзывы. Система позволяет собирать мнения клиентов, анализировать результаты оценок и определять основные проблемы в процессе обслуживания. Руководитель организации получает возможность просматривать отзывы, изучать средние оценки и контролировать качество работы сотрудников. Клиенты могут пользоваться системой через веб-браузер, не посещая организацию повторно. Полученные данные помогают организации улучшать качество услуг и повышать удовлетворённость клиентов.

### Проблемы текущего процесса

- Оценки клиентов собираются на бумаге или устно, поэтому часть отзывов теряется.
- Руководителю сложно быстро определить общий уровень качества обслуживания и выявить недостатки.
- Анализ отзывов занимает много времени, поскольку информация хранится в разных документах.

### 3.1. Оценка качества обслуживания (подробно)

**Начало процесса:** клиент получил услугу и хочет оценить качество обслуживания.

1. Клиент открывает веб-сайт и переходит в раздел оценки качества обслуживания.
2. Клиент выбирает услугу, которую получил.
3. Система отображает критерии оценки: вежливость сотрудника, скорость обслуживания и качество предоставленной услуги.
4. Клиент выставляет оценки по каждому критерию.
5. Клиент при необходимости оставляет письменный отзыв или комментарий.
6. Система проверяет заполненные данные и правильность оценок.
7. После проверки система сохраняет оценку и присваивает отзыву статус «опубликован».
8. Руководитель организации просматривает полученные оценки и отзывы.
9. Система использует сохранённые оценки для формирования статистики и отчётов.

**Результат:** оценка и отзыв клиента сохранены в системе, а руководство получает данные для анализа качества обслуживания.

## 6. Источники требований

Для определения требований к веб-проекту использованы следующие методы:

### 1. Интервью

Проведено условное интервью с представителем организации, отвечающим за качество обслуживания. В ходе интервью рассмотрены следующие вопросы:

1. Каким способом сейчас собираются отзывы клиентов?
2. Какие основные проблемы возникают при сборе отзывов?
3. Какие услуги чаще всего оценивают клиенты?
4. По каким критериям необходимо оценивать качество обслуживания?
5. Какую шкалу оценивания следует использовать?
6. Должен ли клиент оставлять письменный комментарий?
7. Кто должен иметь доступ к результатам оценивания?
8. Какие сведения необходимо отображать в отчётах?
9. Нужно ли сохранять историю оценок клиентов?
10. Как организация будет использовать полученные отзывы для улучшения обслуживания?

**Результат интервью:** определены основные роли пользователей, критерии оценки, необходимость сохранения отзывов и формирования статистических отчётов.

### 2. Изучение аналогов

Изучены примеры веб-систем и онлайн-платформ, предназначенных для сбора отзывов и оценки качества обслуживания клиентов.

**Результат изучения:** определены полезные возможности аналогичных систем: выставление оценок, добавление комментариев, просмотр отзывов, фильтрация данных и формирование статистики.

На основании собранной информации определены основные функции и требования к разрабатываемому веб-проекту.
